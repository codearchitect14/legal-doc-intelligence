# Sample Case Data

The demonstration case folder at `data/sample_case_folder/` is assembled in Phase 2/Phase 7, built from genuinely real, publicly available documents:

- CourtListener filings
- SEC EDGAR contract exhibits
- CORD/SROIE/FUNSD scans
- Blank IRS/DOL forms with fictional figures overlaid
- mtsamples reports

Full sourcing detail is in `PROJECT_PLAN_v2.md` Section 11.

Any figures inserted into government form templates for demonstration purposes are clearly fictional and labeled as such. No real client data is ever used.
